项目详情 ↗

从研究需求到可执行的准备流程

将研究规划拆解为需求澄清、画像确认、问卷设计与提纲准备等环节，串联生成、修改和材料导入能力。通过结构化问题与确认流程，将用户选择和修改结果转化为后续工具执行的明确依据。

让 Agent 按当前业务状态行动

多轮对话中，用户需求、页面上的内容和历史消息可能不一致。我在规划前引入当前业务状态读取，明确已保存事实与历史对话的优先关系，并区分“内容不存在”和“读取失败”，约束重复生成与错误覆盖。针对画像和筛选问卷，进一步处理条件对齐与局部修改，保留未被要求改变的内容。

检查修改是否真正落地

搭建会话重放链路，在隔离的项目状态中重新执行对话，并核对实际保存的业务结果。已实现的检查包括：确认的画像与条件是否保留、取消的内容是否残留，以及是否产生重复画像，让验证落到业务状态上。

GamePlayer

腾讯科技（深圳）有限公司

面向《王者荣耀》的 GUI 自动化测试 Agent，结合游戏截图与结构化 UI 信息，支持从测试用例到游戏内操作的自动执行。

项目详情 ↗

将游戏界面整理为 Agent 可用的观察

游戏界面同时包含画面信息与 UI 控件结构。我结合游戏截图和 UI dump 作为模型输入，针对控件树的结构特点设计剪枝与合并，整理供 Agent 使用的结构化界面信息，控制冗余内容对决策的干扰。

按职责组织领域知识

根据不同 Agent 的职责拆分专有知识库，将相应的领域知识组织到各自的上下文中，为规划与执行提供依据。项目中不仅需要组织工具调用，也需要明确每个角色应该获得哪些信息。

从测试用例走到交互执行

采用 PAE 与 ReAct 结合的双循环架构，串联测试用例理解、任务规划、界面观察与交互执行。执行过程中根据观察与反馈继续组织操作，将测试步骤落实到游戏内动作；操作方式包括测试 SDK，以及坐标、按键和滑动。

将执行经验沉淀为 Playbook

通过 Agent 对执行过程进行反思，归纳可复用的操作规律，并以 Playbook 供后续任务使用。目标是减少重复探索和人工编写操作经验的工作，将单次任务中的经验用于后续执行。

02 · Journey

2014—2017

甘肃省酒泉中学

1999年，我出生于西北的一个小县城，高中毕业之前我都生活在这个城市里，除了旅游之外几乎没有踏出过省外。值得庆幸的是我学习成绩尚可，也一直担任班长，甚至小学时还兼任大队长（aka迄今为止的人生最高职级）。

2017—2021

西安电子科技大学

2017年我录取至西安电子科技大学，所谓的984.5。也是成年后头一次开始在别的地方生活，因为高考分数的窘迫和对所谓高科技的热情选了没那么喜欢的理工科学校，心里有一千个不愿意。但好在我遇到了很多好朋友，担任班长的同时，也在全校面前表演过节目，本科四年是收获满满的四年，拿了国奖保了研，回想起当初，如果能对AI再下点功夫钻研学习就好了。

2021—2024

天津大学

2021年我来到了天津大学，同样还是北方，隔壁的南开是我高中时梦想中的学府，这对天大来说何尝不是一种殃及池鱼呢。在陈俊洁老师的帮助下我成功学习了如何做科研，发表了两篇A会（均不是第一作者），也顺利去了华为诺亚方舟实验室和百度的大搜进行实习，同期的本科朋友大家都在努力科研，而我稍稍显得有点脱轨了。随着接触到更大的世界，这是我最suffer的两年半。

2024—2026

腾讯科技（深圳）有限公司

2024年毕业，这次我来了深圳。至此算是完成了小镇做题家的任务：努力学习，进入大厂。虽然这份答卷可能我没能努力做到满分，但进入腾讯也算我人生的高光时刻了。与此同时，我也失去了目标，虽然在腾讯生活能让我享受到这个巨大的机器运作时带给我的荣誉感，但荣誉感背后藏着的，是我看不到的未来，或者说只能看到那些我不想要的未来。

2026

元衍万物（上海）人工智能科技有限公司

2026年，在腾讯一年半拿下一个五星绩效之后，我毅然决然离职，认为在AI时代大厂存在极其多的局限性，想实现自我的社会价值还是要去真正需要自己也适合自己的地方。因此鼓足勇气踏出了一步，从深圳跑到了上海，可也只用了半年就发现真实的世界从来没有想象中那么简单，不过问题不大，我愿意相信故事还没结束，相信未来就在前方。
